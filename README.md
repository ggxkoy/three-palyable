# Canyon Dozer Playable

基于 Three.js、TypeScript 和 Vite 构建的竖屏推土机 playable。玩家通过拖拽控制推土机，将宝石推过倍率门并送入终点收集区。

## 运行

```bash
npm install
npm run dev
```

默认开发地址为 `http://127.0.0.1:5173/`。

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。
